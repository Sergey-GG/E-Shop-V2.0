# E-Shop Update v2.0 - [EN]

**E-Shop Update v2.0** is an updated version of the educational web application that includes:
- integration of a full-featured relational **PostgreSQL** database instead of plain `.txt` files;
- extended functionality and improved architecture;
- enhanced modularity and clearer separation of responsibilities.

## Key Updates

- Migration to PostgreSQL as the primary data storage
- Expanded project architecture
- Improved user management system
- Integration of unit testing
- Updated user interface
- Added access error handling pages

## Technologies and Tools Used

- Java 11+
- Spring Core
- Spring MVC
- Spring Boot
- Hibernate Validator
- PostgreSQL
- Thymeleaf
- Lombok
- Maven
